# Landschap

**Canonieke mal staat in** `E:\LLM_Workspace\Burger_Interface\Landschap\`.  
Deze map is dezelfde schema-laag. Instanties: Zaakdossier 21a/b/c, niet hier.

Schema, geen casus. Drie vragen die bij elke wederpartij hetzelfde zijn:

1. **Wie zit waar, met welke publieke achtergrond?** — `01_Organisatie.md`
2. **Wie voert uit, onder welk contract, wie houdt toezicht?** — `03_Keten_en_contracten.md`
3. **Wat is het politieke gesprek over thema X?** — `02_Politiek_discours.md`

Thema X is vrij: Wmo, homelessness, uitkering, onderwijs, wat de zaak is. De mal verandert niet. De vulling wel.

**Vulling hoort in het zaakdossier**, als kopie van deze drie bladen. Niet hier. Een ingevuld exemplaar (bijvoorbeeld Zaakdossier stuk 21) is een instantie, geen sjabloon.

## Wat dit niet is

- Geen software, geen installer.
- Geen vijandkaart en geen bijlage bij brieven aan de wederpartij.
- Geen privéleven, huisadres, familie, medische gegevens van ambtenaren.
- Niet in `UK_Housing_Letters`.
